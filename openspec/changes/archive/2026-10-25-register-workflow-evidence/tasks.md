## 1. 証拠の登録

- [x] 1.1 evidence CLIと入力検証、既存lockによる排他、外部証拠の追記保存を追加する。正常登録、元ファイルの変更・消失、不正JSON・項目・日時・64KiB超過、running・completed・ロック中の拒否を検証し、失敗時に状態が変わらないことを確認する。
- [x] 1.2 登録時にsessionだけを無効化し、状態・質問・回答・エラー・権限・試行数を維持する。ready・waiting・failed・limited・blockedの各状態と、旧状態の既存evidence保持をテストする。

## 2. 入力への反映

- [x] 2.1 名前ごとの最新版と有効性を試行開始時に確定し、有効内容・期限切れの明示・利用上の指示をpromptへ加え、渡した登録識別子を試行に保存する。期限境界、最新版失効時の旧版への非復帰、元ファイル不要、対象と用途確認の指示、権限非拡張をテストする。
- [x] 2.2 セッション再開前に証拠の変更・失効を再評価し、必要なら回答を含む新規入力へ戻す。登録後のanswer、retry、回答待ち中の失効、証拠が変わらない通常resumeをテストする。
