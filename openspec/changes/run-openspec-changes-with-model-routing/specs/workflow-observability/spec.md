## MODIFIED Requirements

### Requirement: 試行ごとの性能を記録する
実行器は、試行番号・工程・成否・開始と終了・入力・キャッシュ入力・出力トークンを本リポジトリに記録しなければならない（MUST）。あわせて、使用したCLI・モデル・推論レベル・セッション、新規か再開かの区別、取得できた場合は試行前後の利用枠を記録する。usageや利用枠の未取得値を0と扱わず、キャッシュ入力を入力の内訳として集計する。失敗と再試行を含め、計測にモデルを使わない。

#### Scenario: 環境エラー後に再実行する
- **WHEN** 1つの工程が失敗し、新しいコンテキストで成功する
- **THEN** 2つの試行を別々に記録し、両方の時間と取得できたusageを合計に含める

#### Scenario: usageが取得できない
- **WHEN** ある試行のusageがログに含まれない
- **THEN** 未取得と表示し、取得済みの合計を全試行の完全な合計とは示さない

#### Scenario: CodexとClaudeの試行が混在する
- **WHEN** 1つのワークフローでClaudeの実行前レビューとCodexのapplyを実行する
- **THEN** 各試行のCLI・モデル・推論レベルとusageが区別して記録され、集計に含まれる

#### Scenario: 利用枠の消費を見直す
- **WHEN** 試行の前後で利用枠を取得できる
- **THEN** 前後の使用率を記録し、固定値の見直しに使えるようにする
